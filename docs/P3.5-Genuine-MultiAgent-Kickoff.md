# P3.5 Kickoff — Make it GENUINELY multi-agent (paste into Claude Code)

Read CLAUDE.md, docs/00 — Build Brief.md, docs/P2-Agent-Logic-Spec.md, docs/DESIGN-TOKENS.md first.

## Why this phase exists (read carefully)
P1–P2 built a DETERMINISTIC RULE-ENGINE, not a reasoning multi-agent system. Right now: no LLM in
the run path; the router fans out to ALL agents unconditionally; reconcile is a rule-merge; the UI
shows four canned lenses. It reads as a chatbot with four buttons — nothing reveals reasoning,
handoff, or deliberation. This phase adds the intelligence and makes the process visible. Reuse the
existing graph, config schema, trace schema, streaming groundwork and tests — do NOT rewrite them;
upgrade the nodes.

## Prerequisite
The run path now REQUIRES a working OpenAI-compatible model endpoint (MODEL_PROVIDER / MODEL_NAME /
MODEL_BASE_URL / MODEL_API_KEY in .env). Wire the existing model/client.py into the run path. If no
key is set, fall back to the current deterministic path with a clear "reasoning disabled — set a
model key" banner, so the app still runs.

## Build, in order
1. AGENTS REASON (not just compute):
   - Keep each agent's deterministic hard-signal computation from its config (margin breach, forecast
     flag, effective-RAG, weakest-of-four, tolerance breach) — these stay testable and are the guardrail.
   - Add an LLM reasoning step: the agent's config (lens + rules_summary) becomes its SYSTEM PROMPT;
     the LLM reasons over the input facts + the computed signals to produce genuine analysis:
     reasoning (prose), driving_constraint, lead_figure. The STANCE must stay consistent with the hard
     signals (if the margin math says breach, Finance cannot return yes) — LLM reasons within the rule,
     never overrides it. Structured output (stance | reasoning | driving_constraint | lead_figure).
2. ROUTING IS A REAL DECISION:
   - Replace the unconditional fan-out. The master LLM reads the input and selects WHICH agents are
     relevant, with a one-line reason each (including any it deliberately skips). Emit this as the
     first trace event. Use LangGraph conditional edges / Send to dispatch only the selected agents.
     Keep termination bounded (one routing pass, one specialist superstep, one reconcile).
3. FREE-TEXT IS PRIMARY:
   - Enable a real free-text input the router parses. The four seeds become one-click EXAMPLES, not
     the only way in. (This alone removes most of the "four buttons" feel.)
4. RECONCILE IS DELIBERATION:
   - The master LLM genuinely weighs the conflicting positions — names the trade-off from the agents'
     real constraints, applies the disclosed operational-blocker-wins policy, and always outputs
     recommendation + assumptions + what-it-did-not-consider. Not a merge.
5. STREAM + SHOW THE PROCESS (the UI is the proof it's multi-agent):
   - SSE-stream every step. The UI must visibly show, in sequence: the router THINKING and choosing
     agents (handoff) -> the chosen agents working IN PARALLEL with a live pending->thinking->done
     state, their reasoning streaming token-by-token -> positions as stance cards -> the CONFLICT made
     the focal point -> the master DELIBERATING -> the verdict. Add a small live pipeline/graph view
     (route -> [agents] -> reconcile) with nodes activating as they run, so "how it works in the
     background" is literally on screen. Substance first; apply the Voyij design tokens once the
     process view works.
6. TESTS:
   - Keep the deterministic hard-signal + config-swap tests (mock the LLM). Add: router selects a
     subset for a scoped input; an agent's stance never contradicts its hard signal; reconcile applies
     the blocker policy. LLM mocked in all tests.

## Acceptance bar
Type a free-text back-office dilemma (not a seed) -> watch the master decide who to involve -> watch
the chosen agents reason live and in parallel -> see them genuinely disagree -> watch the master
deliberate and adjudicate. A non-technical viewer sees handoff, parallel work, and deliberation. If
it still looks like four canned lenses, it has failed.
