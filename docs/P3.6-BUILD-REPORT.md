## 6. Where I deviated from, or fell short of, the spec (read this)

- **Process:** `rules.py`, `base.py`/`evidence.py` and the safety-layer tests were written before/with their tests, not
  strictly failing-first (each commit says so). The orchestration, golden-regression and registry tests were
  confirmed failing before the migrations that fixed them (16 → 0 failures across the four migration commits).
- **§6.1** name resolution was first built with config winning on a collision (merge order backwards vs the spec). **Fixed after review:** precedence is now facts > derived > config (`_rule_env()`), and config load rejects any config scalar or derived name that matches a facts field, so no collision can exist. Tested in `test_registry.py`.
- **§6.3** the golden test does not read `migration-diffs.md` to allow listed diffs — moot with zero diffs, but the
  mechanism the spec describes does not exist.
- **§6.8** the triggered-card test asserts stance + "seeded", not the fired rule's description text;
  "Council tab: invalid rule shows the validation error" isn't built (the UI edits thresholds/notes, not `rules[]`).
  The Dashboard "latest signals" tiles are static sample data, untouched.
- **Extension found late (fixed in the last commit):** extraction didn't type-check values (a string for a numeric
  field would have crashed a rule) and PMO's dict-shaped fact couldn't be extracted at all — both fixed and tested.
- **Untested against a real model:** nothing here has been run with a live LLM. Extraction prompt quality, JSON
  shapes from real providers, and the evaluation hit rate are unknown. `MODEL_CONTEXT_TOKENS` uses a ~3 chars/token
  heuristic, not a tokenizer.
- **README screenshots are stale:** `docs/images/council-glossary.png` still shows the old "Routing" row;
  `council-specialists.png` predates the blocker-rule display. Re-capture from your live instance (I did not replace
  your screenshots).
- Unrelated working-tree items I left alone: a pre-existing modified `.gitignore`, local working folders.
  Private docs untouched.
